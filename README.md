# Netro Pharmacy — Inventory & Point of Sale (POS) System

A dedicated healthcare pharmacy management system built with **React JS**, **Redux Toolkit**, **Vite**, and **Tailwind CSS v4**.

## Key Features
- **Multi-Unit Inventory Stock:** Track medicines simultaneously by Carton, Packet/Strip, and Piece with automated mathematical conversions.
- **Counter POS Billing:** Rapid medicine search, multi-unit price selection, cart calculation, and bill settlement.
- **FEFO Expiry Management:** First Expired, First Out automated expiry detection and low-stock re-order alerts.
- **WhatsApp PDF & SMS Invoicing:** Export and dispatch digital PDF invoices to customers via WhatsApp and short bill summaries via SMS.
- **Membership Program:** Auto-generated 10% discount on valid Member ID.
- **Multi-Branch Ready:** Centralized oversight across multiple pharmacy retail outlets.

## Quick Start
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Production build
npm run build
```
